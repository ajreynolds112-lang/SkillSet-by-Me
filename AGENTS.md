# Agent instructions

This repo is a skill library. The full list, with a one-line trigger for each skill, is in [SKILLS.md](SKILLS.md).

- At the start of each task, read `skills/using-agent-skills/SKILL.md`, then load only the skills whose descriptions match the task.
- Never preload every skill. Each one costs context.
- Paths inside a skill are relative to that skill's folder.
