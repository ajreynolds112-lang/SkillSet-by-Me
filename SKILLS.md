# SkillSet by Me: skill list

82 agent skills. Each one is a folder in `skills/` holding a `SKILL.md` (name + description frontmatter, then instructions) and sometimes scripts or reference files.

## Instructions for the agent reading this

1. Do not load every skill. Read this list, pick only the skills whose description matches the current task, and open their `SKILL.md`.
2. At the start of a task, open `using-agent-skills` first. It decides which other skills apply.
3. If you can't read local files, fetch the raw link in the table.
4. When a skill references a file next to it (`references/...`, `scripts/...`), resolve that path relative to the skill's folder.
